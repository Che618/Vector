# 科学数据张量底座与Token化价值运营平台

面向科学数据处理工具集成、贡献确认与长效供给的一体化系统。解压离线包，双击根目录 index.html。推荐桌面版 Chrome 或 Edge。演示输入保存在当前浏览器，文件模式下的持久化取决于浏览器。也可在解压目录运行 python -m http.server 8000，从 http://localhost:8000 打开。

## 三个同级工作空间

工具集成与管理预留工具目录、注册与接入、处理链配置、评价与运维、社区扩展五个页面。各页在 portal/navigation.js 定义标题、字段与版块，在 index.html 的工具模块模板中扩展。当前显示结构和字段，不接入业务服务。

Token收益分配与供给共八页，包括收益与供给总览、使用与计量、贡献确认、分配试算、结算台账、权益兑换、长效供给和业务追溯。portal/operations.js 负责计量、核验、结算与验收。portal/platform.js 负责本地工作区、路由和交互。portal/portal.css 管理平台样式，portal/value.css 对齐张量向量库的经典蓝色主题。Vue 运行库及图形资源均已内置。

张量向量库沿用原有九页 Vue 3 应用。vector.html 是完整原入口，原资源和样式位于 js、styles、assets 和 vendor 中。单独运行向量库时也可直接打开 vector.html。VECTOR-README.md 保留原九页的说明。

## 汇报演示

打开《平台逐页汇报说明.docx》可按页讲解。总览的统计范围可切换本期或历史批次，三项收入均可打开对应流水。快速演示按下列顺序进行。

1. 打开“使用与计量”。本期数据、工具和智能体分别记录 940 条、58 次与 29 次成功调用。单价分别为 2、18 与 45 Token，合计 4,229 Token。
2. 打开“贡献确认”。确认 JOB-11-3 的有效调用，对 JOB-11-1 的重复上报选择排除。需要补充基础交付时，点击“申报贡献”。
3. 打开“分配试算”，点任一主体的“计算依据”。示例权重为 45%、30%、25%。成本取整 422，供给留存取整 634，剩余 3,173 分到主体；主体金额按最大余数法取整。将权重改为 50%、25%、25%，点击“重新试算”，比较原方案、试算方案和变化额。点击“提交结算”和“确认入账”，再打开该批快照。
4. 在权益兑换选择主体，兑换 1 份服务并登记核销。核销生成使用流水和待核验事件，收入为 0，权益额度只扣减一次。
5. 在长效供给提交 BX-17 补录任务的 24 条订正记录、版本 v1.3 和质量报告编号。验收后，责任方获得 160 Token，生成维护贡献。以后的资源使用按新版本计量。该项维护已由供给任务支付，不会再次进入主体分成。
6. 收益与供给总览内的“演示指引”可恢复收益分配与供给示例。恢复需要确认，仅作用于价值运营工作区。向量库有独立的数据存储。

## 实现范围

金额均为整数演示服务权益单位。业务围绕浏览器内的演示数据运行，贡献核验和供给验收由演示操作者完成。上线应用所需的生产身份、外部凭证核销和跨机构结算由后续服务提供。本演示使用独立的运营样例，工具目录和向量库没有自动推送运营事件。

## 验证

在压缩包根目录运行 node scripts/verify-operations.cjs 可检查重复凭据、规则、金额守恒、快照、服务核销、供给验收和后续计量。浏览网页无需安装 Node.js。
